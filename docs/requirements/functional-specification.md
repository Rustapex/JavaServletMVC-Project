# 영화 예매 및 리뷰 시스템 기능 명세서 - 완성본

범위: KMDb 영화상세정보 API 일부 필드 사용, 누적관람인원/누적매출액 제외, MVC2 Servlet + JSP 기준

## 1. 개요

본 시스템은 KMDb 영화상세정보 API를 활용하여 영화 기본 정보를 제공하고, 사용자가 상영 일정 조회, 좌석 선택, 예매, 리뷰 작성, 친구 기반 비공개 리뷰 공유, 필름 다이어리 기능을 이용할 수 있는 웹 서비스이다. 영화 API 정보는 `MOVIE` 테이블에 캐시 저장하고 서비스 핵심 데이터는 Oracle DB에서 관리한다.

## 2. KMDb API 사용 범위

| 구분 | 사용 값 | 설명 |
|---|---|---|
| 요청인자 | `ServiceKey` | API 인증키. 서버 코드에서 관리하고 JSP에 직접 노출하지 않는다. |
| 요청인자 | `collection` | 검색 대상 컬렉션. 영화상세 API 기준 `kmdb_new2` 사용. |
| 요청인자 | `query/title` | 영화 검색어 또는 영화명. |
| 요청인자 | `detail` | 상세정보가 필요하면 `Y`로 요청. |
| 요청인자 | `listCount/startCount` | 검색 결과 개수 및 시작 번호. |
| 요청인자 | `movieId/movieSeq` | 특정 영화 상세 재조회 시 사용. |
| 출력값 | `movieId + movieSeq` | KMDb 영화 식별자. `MOVIE`의 중복 저장 방지 키. |
| 출력값 | `title`, `directorNm`, `actorNm` | 영화명, 감독명, 배우명. 배우는 다중값이므로 `MOVIE_ACTOR`에 저장. |
| 출력값 | `company`, `plot`, `runtime` | 제작사, 줄거리, 상영시간. |
| 출력값 | `repRlsDate 또는 releaseDate` | 대표 개봉일/개봉일자 중 하나만 사용. |
| 출력값 | `posterUrl/posters`, `vodUrl`, `keywords` | 포스터, VOD URL, 키워드. 키워드는 `MOVIE_KEYWORD`에 저장. |

## 3. 주요 기능

| 분류 | 기능 | 설명 | 권한/비고 |
|---|---|---|---|
| 회원 | 회원가입/로그인/로그아웃 | 회원 가입, 로그인 세션 생성, 로그아웃 처리 | 로그인 세션명: `loginMember` |
| 영화 | 영화 검색 | KMDb API에 `query/title` 요청인자를 보내 검색 결과 조회 | 비로그인 가능 |
| 영화 | 영화 상세 조회 | KMDb API 상세 조회 후 `MOVIE`에 없으면 저장, `MOVIE_ID` 확보 | 비로그인 가능 |
| 영화 | 영화 DB 저장 | `MOVIE`, `MOVIE_ACTOR`, `MOVIE_KEYWORD` 저장 | 예매/리뷰 전 내부 처리 또는 AJAX |
| 상영 | 상영 시간 조회 | 영화별 상영 일정 조회 | JSON 가능 |
| 예매 | 좌석 조회/확인 | 상영 일정별 전체 좌석과 이미 예매된 좌석 조회 | AJAX, 중복 예매 방지 |
| 예매 | 예매 확정 | 선택 좌석을 `RESERVATION`/`RESERVATION_SEAT`에 저장 | 로그인 필요 |
| 예매 | 예매 내역/상세/취소/변경 | 본인 예매 내역 관리 | 본인만 가능 |
| 리뷰 | 리뷰 목록 조회 | `MOVIE_ID` 기준 리뷰 조회. 공개 리뷰는 전체 조회, 비공개는 본인/친구만 조회 | 비공개 권한 반영 |
| 리뷰 | 리뷰 등록/수정/삭제 | 신선도, 공개 여부, 리뷰 내용 관리 | 작성자 본인만 수정/삭제 |
| 리뷰 | 리뷰 통계/필터 | 공개 리뷰 기준 신선/비신선 통계, 최신순/오래된순/신선/비신선/내 리뷰 필터 | JSON 가능 |
| 친구 | 친구 목록/추가/삭제/확인 | 양방향 친구 관계 관리 | 자기 자신/중복/없는 회원 방지 |
| 다이어리 | 필름 다이어리 | 예매 완료 시 자동 기록, 날짜별 영화 표시, 감정 태그 관리 | 본인만 가능 |

## 5. 핵심 흐름

영화 검색 -> KMDb API 응답 수신 -> 필요한 출력값을 MovieDTO에 담음 ->
MOVIE/MOVIE_ACTOR/MOVIE_KEYWORD 저장 또는 기존 MOVIE_ID 조회 -> 상영 일정 선택 -> 좌석 선택 ->
예매 확정 -> 필름 다이어리 자동 등록 -> 리뷰 작성 및 공개/비공개 설정 -> 친구 관계에 따라 비공개 리뷰 조회 허용.
