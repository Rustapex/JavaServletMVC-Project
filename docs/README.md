# 프로젝트 문서

이 디렉터리는 영화 예매 및 리뷰 시스템의 유지 가능한 문서를 보관합니다.

| 문서 | 위치 | 설명 |
| --- | --- | --- |
| 기능 명세 | `requirements/functional-specification.md` | 사용자 기능, 권한, 핵심 흐름 |
| 데이터베이스 | `database/README.md`, `database/erd.png` | ERD와 DB 문서 작성 기준 |
| 참고 자료 | `reference/` | API 사용 메모와 기존 개발 명세 원본 |

## 보관 원칙

- Markdown을 수정 가능한 기준 문서로 사용합니다.
- 실제 접속 주소, 비밀번호, API 키는 문서에 기록하지 않습니다.
- PDF, ZIP, 테스트 결과 원본처럼 중복되거나 대용량인 자료는 Git에 추가하지 않습니다.
