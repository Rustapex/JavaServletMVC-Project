영화 예매 및 리뷰 시스템 - MVC 개발명세서 수정본

Servlet + JSP 기반 MVC2 개발명세서입니다. View가 JSP이면 화면 출력, JSON이면 AJAX 응답, 재요청은 처리 후 redirect 기준입니다.
영화 기준 조회는 api_movie_id가 아니라 MOVIE_ID를 사용합니다. KMDb API 값은 MOVIE 테이블에 저장한 뒤, 예매/리뷰/다이어리에서 MOVIE_ID로 참조합니다.

공통 약속
세션 로그인 회원명: loginMember
JSP 위치: /WEB-INF/views/
JSON 응답: 좌석 조회, 영화 저장, 리뷰 목록/필터, 친구 검색 등 AJAX 기능에서 사용
KMDb API 저장 테이블: MOVIE, MOVIE_ACTOR, MOVIE_KEYWORD
영화 검색 목록 화면은 MovieSearchResultDTO를 request attribute result로 전달합니다.
이번 수정 반영 내용
  • MovieSearchServlet은 query/page를 받고 MovieSearchService.search(query, page)만 호출하도록 변경
  • MovieSearchService를 추가하여 API 호출, 페이징 생성, 목록 출력용 DTO 변환 담당
  • PagingDTO를 추가하여 totalPage, startPage, endPage, hasPrev, hasNext 계산 담당
  • MovieListItemDTO, MovieApiSearchResultDTO, MovieSearchResultDTO 추가
  • movieList.jsp는 result.movieItems, result.paging만 출력하도록 변경
  • 영화 검색 한 페이지 출력 개수는 12개, 페이지 번호 묶음은 5개 기준

영화 검색 MVC2 상세 분리

구분파일/클래스역할
ControllerMovieSearchServletquery/page 파라미터를 받고 MovieSearchService.search(query, page)를 호출한다. 반환받은 MovieSearchResultDTO를 request의 result로 담고 /WEB-INF/views/movieList.jsp로 forward한다.
ServiceMovieSearchServiceMovieApiService를 호출하고, PagingDTO를 생성하며, MovieDTO 목록을 MovieListItemDTO 목록으로 변환한다. 최종적으로 MovieSearchResultDTO를 반환한다.
API ServiceMovieApiServiceKMDb API 요청 URL 생성, GET 요청, JSON 파싱, MovieDTO 생성, totalCount 추출을 담당한다. listCount/pageSize는 12개 기준으로 호출된다.
DTOPagingDTOcurrentPage, pageSize, pageBlockSize, totalCount를 기준으로 totalPage, startPage, endPage, hasPrev, hasNext, prevPage, nextPage, pageNumbers를 계산한다.
DTOMovieListItemDTOmovieList.jsp 카드 출력에 필요한 값만 보관한다. KMDb movieId, movieSeq, title, directorNm, displayReleaseDate, posterUrl을 가진다.
DTOMovieApiSearchResultDTOMovieApiService가 반환하는 API 검색 결과 묶음이다. MovieDTO 목록과 totalCount를 담는다.
DTOMovieSearchResultDTOMovieSearchService가 Servlet에 반환하는 최종 결과 묶음이다. query, hasQuery, hasResult, movieItems, paging을 담는다.
ViewmovieList.jspresult.movieItems와 result.paging을 JSTL/EL로 출력한다. API 호출, DB 처리, 페이징 공식, 날짜 변환 로직은 작성하지 않는다.

ServiceMovieServiceAPI에서 받은 영화 정보를 DB에 저장하고 MOVIE_ID 반환

영화 검색 요청 흐름

  1. 사용자가 /movie/search.do?query=검색어&page=1로 요청한다.
  2. MovieSearchServlet이 query와 page를 받는다.
  3. MovieSearchServlet이 MovieSearchService.search(query, page)를 호출한다.
  4. MovieSearchService가 MovieApiService.searchMovies(query, page, 12)를 호출한다.
  5. MovieApiService가 KMDb API를 호출하고 JSON을 파싱하여 MovieApiSearchResultDTO를 반환한다.
  6. MovieSearchService가 PagingDTO를 만들고 MovieDTO를 MovieListItemDTO로 변환한다.
  7. MovieSearchService가 MovieSearchResultDTO를 Servlet에 반환한다.
  8. MovieSearchServlet이 request.setAttribute("result", result)로 저장하고 movieList.jsp로 forward한다.
  9. movieList.jsp는 result.movieItems와 result.paging을 출력한다.
